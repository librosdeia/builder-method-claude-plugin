# Builder Method — Claude plugin

A plugin for Claude Code and Cowork that guides you, step by step, from a vague idea to a published product using the Builder Method: idea, PRD, design, build, iterate and ship. It keeps your progress in a visible `builder/` folder, warns you when you skip a step, and shows a visual map of where you are and what is missing.

Work in progress — v0.1 is under construction. Full documentation coming soon (English and Spanish).
