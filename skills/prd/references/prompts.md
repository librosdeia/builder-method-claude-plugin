# Builder Method — original PRD prompts (English)

The skill follows their intent; the user never has to type them. In the course, "Clarify" was run in plan mode. Here that means: ask and plan before writing anything.

## Clarify
> I have a product idea. Help me pin down everything needed to write a PRD I can hand to Claude Code. <the idea document>

## Write
> Write what we've discussed as a PRD I can give to Claude to build.

## Review
> Review the PRD for mistakes, contradictions, gaps and important missing definitions. Focus especially on the user experience (UX/UI), and add a design section that specifies the user flows.

## Polish flows (optional)
> Review the user flows again, looking for contradictions and friction points, so the product is easy to use and understand.
