# Design brief template

Fill this from the PRD and give it to the user to paste into Claude (a chat, or Cowork) to design the screens there, as a Claude Design artifact. Write it in the user's language.

---

Design the screens of **<product name>**, a <one-line summary>.

**Who uses it:** <users and roles>.
**Look and tone:** <design notes from the PRD: tone, colours if any, phone-first or desktop>.
**Constraints:** <accessibility, large buttons, languages…>.

Create one screen (or a short sequence) per user flow, so each flow can be clicked through from start to end:

- **F1 — <name>:** <steps of the flow, one line each> → final screen: <what the user sees when it worked>.
- **F2 — <name>:** …

Also include the empty and error states named in the acceptance criteria (for example: "slot already taken", "too late to cancel").

When you finish, share the link to the design.
