# API

## What it is
A set of addresses where one program asks another for data or actions, in a fixed format. Like a waiter taking orders between the dining room and the kitchen.

## Why it matters
Your app's screens talk to its own back end through an API, and it can use other services (email, maps, payments) the same way.

## Example
When a client presses "Book", the page sends the details to `/api/bookings`, and the server saves them.
