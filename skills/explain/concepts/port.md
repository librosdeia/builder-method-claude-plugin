# Port

## What it is
A numbered door on a computer that a program listens on, so a browser knows where to knock.

## Why it matters
Locally your app might be at `localhost:3000`. Hosts tell the app which port to use, so the code must read it instead of fixing it.

## Example
Open `http://localhost:3000` to see the app while building; on Railway the app uses the `PORT` the host gives it.
